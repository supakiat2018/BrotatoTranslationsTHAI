# 🥔 ม็อดภาษาไทยเกม Brotato (Brotato Thai Translation)

**เวอร์ชัน:** `1.2.0.1`  
**Steam Workshop:** https://steamcommunity.com/sharedfiles/filedetails/?id=3790183731

ม็อดแปลภาษาไทยสมบูรณ์แบบสำหรับเกม **Brotato** รองรับตัวเกมหลัก (**เวอร์ชัน 1.2.0.1**), **DLC Abyssal Terrors** และ **DLC Primal Dread** (แปลครบทั้งหมด!)  
มาพร้อมระบบฟอนต์ภาษาไทย PUA คมชัด สระและวรรณยุกต์จัดตำแหน่งถูกต้อง ไม่ซ้อนทับกัน 100%

---

## ✨ คุณสมบัติเด่น (Features)

- 🎮 **100% Steam Workshop Native:** กด Subscribe แล้วเข้าเล่นได้ทันที ไม่ต้องดาวน์โหลดหรือรันตัวติดตั้งภายนอกใดๆ เพิ่มเติม
- 🏝️ **แปลครบทุกเนื้อหาและ DLC:** รองรับทั้งตัวเกมหลัก, **DLC Abyssal Terrors** และ **DLC Primal Dread** แปลครบทั้งตัวละคร อาวุธ ไอเทม ศัตรู และระบบใหม่ของ DLC
- 🔤 **ฟอนต์ภาษาไทย PUA คมชัด:** สระและวรรณยุกต์ไม่ลอย ไม่ซ้อนทับกัน
- 🔄 **อัปเดตอัตโนมัติ:** รองรับการอัปเดตผ่าน Steam Workshop ได้ทันที

---

## 📥 วิธีการใช้งาน (How to Use)

1. เข้าไปที่หน้า [Steam Workshop - BrotatoTranslationsTHAI](https://steamcommunity.com/sharedfiles/filedetails/?id=3790183731) แล้วกดปุ่ม **Subscribe (สมัครสมาชิก)** สีเขียว
2. เปิดเกม **Brotato**
3. ไปที่เมนู **Options (ตัวเลือก / ตั้งค่า)** ➔ **Language (ภาษา)** ➔ เลือก **"ภาษาไทย"**
4. เริ่มเล่นเกมเป็นภาษาไทยได้ทันที!
